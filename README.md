# all calendar

바탕화면에 붙여 두고 쓰는 Windows용 할 일 달력이에요.
날짜 칸을 더블클릭해 일정을 적고, 원하면 내 구글 캘린더·구글 할 일과 연동할 수 있어요.

## 다운로드

👉 **[최신 버전 받기](https://github.com/predeity/all-calendar/releases/latest)** → `all-calendar-setup-x.x.x.exe` 를 눌러 받으세요.

- Windows 10 / 11 (64비트)
- 내 일정은 내 PC에만 저장돼요. 다른 사람과 공유되지 않아요.

## 설치
1. 받은 `all-calendar-setup-x.x.x.exe` 를 더블클릭해요.
2. **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 눌러요.
   (회사 전자서명이 없는 프로그램이라 처음에 한 번 뜨는 안내예요.)
3. 설치 폴더를 고르고 **설치**를 누르면 바탕화면과 시작 메뉴에 `all calendar`가 생겨요.
4. 창 가장자리를 끌어 크기를, 제목 표시줄을 끌어 위치를 맞춰요.

## 기본 사용법
- 날짜 칸 **더블클릭** → 일정 등록 카드(일정 / 할 일, 날짜·시간, 반복, 알림, 색)
- 칸 속 항목 더블클릭 → 고치기 · 지우기
- 칸 위 **마우스 휠** → 칸 안 목록이 길면 스크롤, 아니면 글자 크기(위로 작게 · 아래로 크게)
- 달력 칸 위의 클릭·끌기·오른쪽 클릭은 바탕화면이 받아요(바탕화면 아이콘·메뉴를 그대로 쓸 수 있어요)
- 제목 표시줄: ‹ › 달 이동 · ▤ 일정 몰아보기 · ⌕ 검색 · G 구글 캘린더 고르기 · ⚙ 설정
- Win+D(바탕화면 보기)를 눌러도 달력은 남아 있어요

## 구글 캘린더 연동 (원할 때만)
1. ⚙ 설정 → **구글 캘린더** → **구글 계정 연결**
2. 브라우저에 구글 로그인 화면이 뜨면 내 계정을 골라요.
3. **"Google에서 확인하지 않은 앱"** 이 나오면 **고급 → all calendar(으)로 이동**을 눌러요.
4. 권한 체크를 모두 켜고 **계속** → "연결했어요"가 보이면 창을 닫아도 돼요.
5. 구글 일정이 달력에 보이고, 일정 카드에서 **[연동]** 에 체크하면 구글에도 올라가요.

- 비밀번호는 all calendar에 저장되지 않아요. 연결 정보는 내 PC에만 암호화해서 보관돼요.
- **회사 구글 계정(Google Workspace)** 은 회사 관리자가 외부 앱 연결을 막아 두었으면 연결되지 않을 수 있어요. 개인 Gmail은 문제없어요.

## 업데이트 · 지우기
- 새 버전이 올라오면 [최신 버전](https://github.com/predeity/all-calendar/releases/latest)을 받아 다시 설치하면 돼요. 내 일정은 그대로 남아요.
- 지우려면 Windows 설정 → 앱 → `all calendar` → 제거. 일정 데이터(`%APPDATA%\all calendar`)는 남겨 둬요.

## 개인정보
일정·할 일·설정은 사용자의 PC에만 저장되고 개발자나 다른 서버로 보내지 않아요.
구글 연동 시 받은 정보는 구글 API 서비스 사용자 데이터 정책(Limited Use 포함)을 따라 달력 표시와 연동에만 써요.
